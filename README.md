## 💡 關於本專案

設立此倉庫的初衷是為了完整保留我的編程學習紀錄。這裡涵蓋了不同難度與主題的演算法題目與代碼實現。希望這些解題思路與代碼能為正在學習程式設計的同好提供一些參考價值，幫助大家突破學習上的瓶頸。

## 🔍 瀏覽方式

您可以直接在 GitHub 網頁端瀏覽各個資料夾內的代碼，或者將整個倉庫下載到本地端以供離線閱讀：

1. 將倉庫 Clone 到本地：

    ```sh
    git clone https://github.com/lcy8787/hkoi-Online-Judge.git
    ```

2. 進入對應的目錄查看題目描述與解答：

    ```sh
    cd HKOI
    ```

## 📌 使用規範

- **僅供參考**：強烈建議讀者在查看解答前先自行思考。請將這裡的代碼作為學習思路的參考，切勿直接抄襲以應付測驗或比賽。
- **不開放貢獻**：本專案為純個人性質的紀錄，**不提供貢獻指南，也不接受任何 Pull Request**。倉庫內的所有內容更新與維護將由作者本人獨立完成。
